# SUI · 语义寻址语言

> **Semantic Unified Interface** —— 一个以大模型为"第一读者"的语义编码协议。
>
> 不是人类自然语言，不是编程语言，而是 AI 可直接寻址的形式化语义中间表示。

---

## 概述

SUI（语义寻址语言）解决大模型推理管线中的结构性浪费：当前 LLM 将自然语言拆成 token、映射到 embedding、通过 attention 计算概率分布来消歧——但**本不该有歧义的步骤大量存在**。字形≠语义，token≠概念，概率消歧≠精确寻址。

SUI 在自然语言与模型推理之间插入一层**形式化语义地址**：将概念、关系、语境态编码为可直接寻址的结构化表示，让模型从"概率猜义"转向"地址定位"。

### 核心定位

| 维度 | 说明 |
|---|---|
| 第一读者 | 大模型（LLM），而非人类 |
| 语言性质 | 语义中间表示，不是自然语言也不是编程语言 |
| 编码目标 | 概念精确寻址、语境态锁存、语义相位追踪 |
| 底层支撑 | CART（认知注意力资源论）/ CCT（认知编码论）/ CSMT（义原矩阵理论）同源三框架 |
| 联动框架 | SCION（提示词寻址篇）—— SUI 管硬编码地址锁存，SCION 管自然语言软路由 |

## 核心机制

### 1. 语义地址编码

将自然语言概念映射到形式化地址空间，包含：
- **概念寻址**：精确锁定语义单元，消除 token 级歧义
- **语境态锁存**：记录当前对话/推理的语义状态分布
- **语义相位追踪**：跟踪语义流转过程中的相位变化与阻滞

### 2. 语境态更新机制

SUI 维护一个信念分布状态转移机，支持：
- 语境态增量更新
- 语义相位流转阻滞检测
- 覆而未灭 ↔ 始复未起的恢复语言

### 3. 主干筛选与维护

基于语义固着度的主干淘汰律，维护核心语义链路，过滤噪声分支。

## 与同源框架的关系

```text
CART（认知注意力资源论）── 底层注意力预算与资源约束
    │
CCT（认知编码论）──────── 编码结构与语义寻址理论
    │
SUI（语义寻址语言）────── 形式化编码协议（本项目）
    │
SCION（提示词寻址篇）──── 自然语言侧软路由（独立篇章）
```

- **CART**：提供注意力预算与资源约束的底层理论
- **CCT**：提供认知编码的结构理论，SUI 是 CCT 的应用层
- **CSMT**：提供义原矩阵的语义分解理论
- **SCION**：与 SUI 是"软路由与硬编码"关系——SCION 管自然语言侧的语义锚定路由，SUI 管锚定后的形式化地址锁存
